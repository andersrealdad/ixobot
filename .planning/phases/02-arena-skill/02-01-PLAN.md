  <action>
Create `nanobot/skills/arena-builder/scripts/arena_run.py` -- a standalone Python script (stdlib only, no pip dependencies) that automates the arena execution flow.

**Usage:** `arena_run.py <task_description_json>`

The `task_description_json` argument is the JSON string from the task_queue `description` field (or a path to a file containing it).

**Constants:**
```python
SHARED_DATA = Path.home() / "shared-data"
WORKSHOP = SHARED_DATA / "DEV" / "garage" / "workshop"
AGENT_GSD = Path.home() / "DEV" / "garage" / "infra" / "octopus" / "agent-gsd.sh"
SHARED_MEMORY_DB = SHARED_DATA / "db" / "shared-memory.db"
TIMEOUT_S = 1800  # 30 minutes
```

**Functions to implement:**

1. `parse_task(task_json: str) -> dict` -- Parse JSON string with keys: bo_id, bo_filepath, model, instruks. Validate all 4 keys present. Accept either a JSON string or a file path to a JSON file.

2. `create_sandbox(bo_id: str, model: str, instruks: str) -> Path` -- Create directory at `WORKSHOP / f"arena-{bo_id}-{model}"`. If it exists, `shutil.rmtree` it first (idempotent). Write `instruks.md` with the instruks text. Return the sandbox path.

3. `run_agent_gsd(sandbox: Path, bo_id: str, model: str) -> tuple[int, float]` -- Run agent-gsd.sh from the sandbox directory:
   ```python
   env = os.environ.copy()
   env["OCTOPUS_MODEL"] = model
   env["OCTOPUS_ORDER_ID"] = bo_id
   result = subprocess.run(
       [str(AGENT_GSD), "instruks.md", "result.json", "quick"],
       cwd=str(sandbox),
       env=env,
       timeout=TIMEOUT_S,
       capture_output=True,
       text=True,
   )
   ```
   Return (exit_code, duration_seconds). On timeout, return (1, TIMEOUT_S).

4. `collect_insights(sandbox: Path, bo_id: str, model: str, exit_code: int, duration_s: float) -> list[dict]` -- Scan sandbox and build insights list:
   - Read `result.json` if it exists, create an observation insight from its status
   - Read `DONE.md` if it exists, create a decision insight from its content
   - Read `FLAG.md` if it exists, create a warning insight (severity=high)
   - Scan `.planning/` for any `*-SUMMARY.md` files, create observation insights from accomplishments
   - List all files in sandbox via `git diff --stat` or `os.walk`, create one observation insight per created file (severity=info)
   - If exit_code != 0 and no FLAG.md, create a warning insight with severity=critical about the failure
   Each insight dict: `{"type": str, "text": str, "edges": list[str], "severity": str}`

5. `write_insights(sandbox: Path, insights: list[dict]) -> Path` -- Write each insight as a JSON line to `sandbox / "insights.jsonl"`. Return the file path.

6. `post_result(agent_name: str, bo_id: str, model: str, status: str, insight_count: int, duration_s: float) -> None` -- Insert into message_bus:
   ```python
   conn = sqlite3.connect(str(SHARED_MEMORY_DB))
   metadata = json.dumps({
       "bo_id": bo_id,
       "model": model,
       "status": status,  # "completed", "flagged", or "error"
       "insight_count": insight_count,
       "duration_s": round(duration_s, 1),
   })
   message = f"Arena BO #{bo_id} ({model}): {status} - {insight_count} insights in {round(duration_s)}s"
   conn.execute(
       "INSERT INTO message_bus (from_agent, to_agent, channel, message, metadata) VALUES (?, ?, ?, ?, ?)",
       (agent_name, "*", "arena-build", message, metadata),
   )
   conn.commit()
   conn.close()
   ```

7. `main()` -- Orchestrate: parse_task -> create_sandbox -> run_agent_gsd -> collect_insights -> write_insights -> post_result. Determine status from exit_code: 0=completed, 2=flagged, else=error. Get agent_name from `NANOBOT_AGENT_NAME` env var (default: "arena-competitor"). Print summary to stdout. Exit 0 always (error-resilient, same pattern as arena_trigger.py).

**Script footer:**
```python
if __name__ == "__main__":
    main()
```

**Error handling pattern** (same as arena_trigger.py): wrap entire main() in try/except, always exit 0, print errors to stderr. Individual function failures should be caught and produce warning-type insights rather than crashing.
