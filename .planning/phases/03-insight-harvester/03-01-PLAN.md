Create `nanobot/skills/arena-builder/scripts/harvest_insights.py` -- a standalone stdlib-only script (plus subprocess for psql) that:

1. **Detects completed BOs**: Queries message_bus in shared-memory.db for arena-build channel rows. Groups by bo_id from metadata JSON. A BO is "harvestable" when it has 2 message_bus rows (both competitors finished). Use this query:
```python
SELECT metadata FROM message_bus WHERE channel = 'arena-build' ORDER BY created_at DESC
```
Parse each row's metadata JSON to extract bo_id. Group by bo_id, only harvest bo_ids with exactly 2 entries.

2. **Deduplication**: Before harvesting a bo_id, check if it already has rows in PostgreSQL:
```bash
ssh stacks "sudo -u postgres psql -d astrid_memory -t -c \"SELECT COUNT(*) FROM ixonaut.arena_build_insights WHERE bo_id = '{bo_id}'\""
```
Skip bo_ids that already have rows (idempotent).

3. **Collects insights.jsonl files**: For each harvestable bo_id, glob sandbox directories:
```python
WORKSHOP = Path.home() / "shared-data" / "DEV" / "garage" / "workshop"
# Pattern: arena-{bo_id}-*/insights.jsonl
for sandbox in WORKSHOP.glob(f"arena-{bo_id}-*/"):
    insights_file = sandbox / "insights.jsonl"
```
Extract model name from directory name: `arena-{bo_id}-{model}` -> model = directory name split on `arena-{bo_id}-` suffix.

4. **Inserts into PostgreSQL**: For each insight line in each insights.jsonl, construct an INSERT and pipe through psql via subprocess:
```python
def insert_insights(bo_id: str, model: str, insights: list[dict]) -> int:
    """Insert insights into PostgreSQL via psql over ssh. Returns count inserted."""
    if not insights:
        return 0

    sql_lines = []
    for ins in insights:
        # Escape single quotes in text
        text_escaped = ins["text"].replace("'", "''")
        edges_json = json.dumps(ins.get("edges", []))
        severity = ins.get("severity", "info")
        insight_type = ins.get("type", "observation")
        builder = f"arena-{model}"

        sql_lines.append(
            f"INSERT INTO ixonaut.arena_build_insights "
            f"(bo_id, model, insight_type, text, edges, severity, builder_identity) "
            f"VALUES ('{bo_id}', '{model}', '{insight_type}', '{text_escaped}', "
            f"'{edges_json}'::jsonb, '{severity}', '{builder}');"
        )

    sql = "\n".join(sql_lines)
    result = subprocess.run(
        ["ssh", "stacks", "sudo -u postgres psql -d astrid_memory"],
        input=sql, capture_output=True, text=True
    )
    return len(sql_lines) if result.returncode == 0 else 0
```

7. **Summary output**: Print how many insights were harvested per bo_id and model.
